# Contribution Guidelines

Contributions are welcome.

## Guidelines

- Ensure tools are relevant to stock/options trading.
- Include a link to the official website.
- Keep descriptions concise (1-2 sentences).
- Note affiliate programs if applicable.
- Add each entry as `- [Name](link) - Description.`
- Start the description with an uppercase letter and end it with a period.

## Adding a tool

1. Fork the repository.
2. Add the tool to the appropriate category with a brief description and link.
3. Submit a pull request.

For suggestions or issues, open an [issue](https://github.com/harmenx/awesome-finance/issues).

## Updating a pull request

If a maintainer asks for changes, update the existing pull request.
