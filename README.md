## 🛠️ Contributing

Contributions are welcome! If you know of a great finance tool that's missing, please:

1. Fork the repository.
2. Add the tool to the appropriate category with a brief description and link.
3. Submit a pull request.

For suggestions or issues, open an [issue](https://github.com/harmenx/awesome-finance/issues) on GitHub.

**Guidelines:**
- Ensure tools are relevant to stock/options trading.
- Include a link to the official website.
- Keep descriptions concise (1-2 sentences).
- Note affiliate programs if applicable.
